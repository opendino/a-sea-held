# A Sea, Held

An AI-assisted interactive ocean study built with Three.js 0.170.0.

**Live demo:** https://opendino.github.io/a-sea-held/

## Explore

- Drag the scene to orbit; scroll or pinch to zoom.
- Drag **Atmosphere** from sunrise to midnight storm.
- Click the whale to descend below the surface.
- Use the reset button or press **R** to return.

Requires a current browser with WebGL. No backend or build step is needed. Serve this directory with any static web server. Three.js and the required add-ons are vendored locally; its MIT license is included in `vendor/three/LICENSE`.

The original scene behavior and interface are retained. Deployment changes localize the pinned Three.js imports and add link-preview metadata.
